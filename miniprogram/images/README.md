# Image Assets

This directory contains all image assets for the 暖账 mini-program.

## Required Images

### TabBar Icons (48x48px recommended)
- home.png - Home tab icon (inactive state)
- home-active.png - Home tab icon (active state)
- stat.png - Statistics tab icon (inactive state)
- stat-active.png - Statistics tab icon (active state)
- mine.png - My tab icon (inactive state)
- mine-active.png - My tab icon (active state)

### Logo
- logo.png - App logo (recommended size: 160x160px, will be displayed as 160rpx x 160rpx)

### Placeholders
- default-avatar.png - Default avatar image for users without a profile picture

## Design Guidelines

- TabBar icons: Orange (#FF9500) when active, Gray (#999999) when inactive
- All icons should be PNG format with transparent backgrounds
- Logo should have orange (#FF9500) or warm gradient theme
