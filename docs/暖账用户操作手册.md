## 1. 简介

暖账是一款家庭协作记账微信小程序。家庭成员可以共同记录日常收支，通过分类统计和饼图查看消费结构，支持邀请家庭成员加入共享账本。

**核心功能：**
- 日常收支记录（支出/收入）
- 分类管理（每个账本独立分类，支持大类/小类新增、改名和删除）
- 月度统计饼图与首页日期分组
- 月度总预算、分类预算、预算进度和超支提醒
- 图片上传与查看
- 家庭成员邀请与协作
- 游客模式与客户端版本更新提醒

## 2. 登录与注册

### 首次使用

1. 打开小程序后默认进入首页，可以先以游客状态浏览首页、统计和"我的"页面。
2. 当需要记账、设置预算、管理家庭或编辑资料时，系统会引导进入登录页。
3. 阅读《用户协议》和《隐私政策》。
4. 勾选"我已阅读并同意以上协议"。
5. 点击"微信一键登录"完成主动登录。

登录成功后自动创建个人账本，并跳转到首页。

### 再次使用

已登录用户再次打开小程序，自动跳过登录页，直接进入首页。

如果用户主动退出登录，小程序会保持游客状态，不会在下一次打开时自动静默登录。再次主动登录后，云端会恢复原有账本、头像昵称和家庭关系。

## 3. 首页

首页展示当月账目概览。

### 汇总卡片

顶部橙色卡片显示当月：
- **支出**（橙色数字）
- **收入**（绿色数字）  
- **结余**（收入 - 支出）

### 预算卡片

首页会显示本月预算状态：
- 未设置预算时，显示"本月预算未设置"和设置入口。
- 已设置预算时，显示已用金额、预算金额、剩余金额和使用进度。
- 当预算接近或超过时，卡片会显示预警或超支状态。

### 月份切换

点击卡片左侧 `<` 和右侧 `>` 按钮切换月份，账目列表和汇总数据同步更新。

### 账目列表

按月展示所有记录，并按日期分组：
- 今天显示"今天"，昨天显示"昨天"，更早记录显示具体日期
- 每个日期分组展示当天收入和支出小计
- 分组内记录按录入时间倒序排列
- 支出显示为负数（橙色）
- 收入显示为正数（绿色）
- 每条记录显示：分类图标、分类名称、备注、金额、记账人
- 有图片的记录在分类名旁显示 📷 标记

已登录用户重新打开小程序时，首页会优先使用本地会话加载记录，再在后台校正登录态，减少首屏等待。

### 快速记账

点击右下角橙色悬浮 `+` 按钮，进入记一笔页面。

### 空状态

当月无账目时显示"本月暂无账目"和"点击右下角按钮记一笔"。游客状态下可以浏览空状态，点击记账或预算入口时再登录。

## 4. 记一笔

### 新增记录

1. 点击首页右下角 `+` 按钮
2. 选择类型：支出（默认）或收入
3. 输入金额
4. 选择分类：点击分类区域弹出分类弹窗
   - 可直接选择大类（如"记在「餐饮」下"）
   - 也可先选大类，再选择小类（如"午餐"）
5. 选择日期（默认当天）
6. 填写备注（可选）
7. 添加图片（可选，最多 9 张）
8. 点击"提交"

如果本次支出触发预算预警或分类预算超支，记录会先保存成功，然后在提交按钮上方显示非阻塞提示条，约 2 秒后自动返回首页。

### 支出分类

支出默认包含 16 个大类：餐饮、交通、购物、居住、通讯、育儿、美容护肤、服饰、娱乐、运动健身、旅行、宠物、医疗、人情、教育、其他。每个大类下都有常用默认小类，也可以按家庭习惯自行调整。

### 收入分类

收入默认包含 7 个大类：工资、奖金、公积金、投资、副业兼职、红包礼金、其他。

### 分类管理

在分类弹窗中点击"管理"，进入独立分类管理页：
- 可在支出/收入 Tab 下新增自定义大类。
- 可修改大类或小类名称和 emoji。
- 可删除自建大类；系统预置大类不能删除，但可以改名或改图标。
- 删除无记录的小类会直接确认删除；删除有记录的小类时，需要选择归并到父类或同父其他小类。
- 删除被当前月或未来预算引用的大类时会被阻止，需要先调整预算。

### 图片上传

- 支持拍照或从相册选择
- 最多可添加 9 张图片
- 提交后图片自动上传到云端
- 家庭成员均可查看图片

## 5. 统计

底部 Tab 切换到"统计"页。

### 饼图

- 月度支出占比环形饼图
- 按大类聚合（如"餐饮 ¥500"）
- 支持触摸交互

### 图例列表

饼图下方显示分类明细：
- 分类名称
- 金额
- 占比百分比
- 按金额降序排列

### 预算进度

- 未设置预算时，统计页保留原有饼图和分类明细，并显示设置预算入口。
- 已设置预算时，统计页显示总预算使用进度。
- 如果设置了分类预算，对应支出大类会显示分类预算使用情况。

### 月份切换

顶部月份选择器可切换查看不同月份的统计数据。

### 空状态

当月无支出时，饼图区域为空，图例显示"本月暂无支出数据"。

## 6. 我的

底部 Tab 切换到"我的"页。

### 个人信息

- 显示当前头像和昵称
- 背景为橙色渐变

### 编辑个人信息

1. 点击头像旁的 ✏️ 按钮打开编辑弹窗
2. **更换头像：** 点击头像，可选择微信头像、拍照或从相册选择
3. **修改昵称：** 在输入框中编辑昵称，支持微信昵称一键填入
4. 点击"保存"统一保存

**注意：** 保存后的头像和昵称会持久保留，退出登录后重新登录仍显示您设置的信息。

### 家庭

点击"家庭"进入家庭管理页面。

### 预算管理

点击"预算管理"进入预算页面：
- 管理员可设置本月总预算和分类预算。
- 管理员可复制上月预算到当前月，当前月已有预算时不会覆盖。
- 管理员可删除当前月预算，删除预算不会删除账目。
- 普通家庭成员可以查看预算和使用进度，但不能修改。
- 历史月份预算仅可查看，不能编辑。

### 关于

查看当前版本号、用户协议和隐私政策。版本号来自统一配置。

### 退出登录

点击"退出登录" → 确认后清除登录状态，跳转到登录页。

## 7. 家庭协作

### 邀请成员（管理员）

1. 进入"我的" → "家庭"
2. 确认自己是账本管理员
3. 点击"邀请成员"按钮
4. 选择微信好友发送分享卡片
5. 好友点击卡片即可申请加入

**邀请说明：**
- 邀请码有效期为 1 小时
- 一次性使用，使用后自动失效
- 可在家庭页查看当前邀请码

### 加入家庭

#### 方式一：点击分享卡片（推荐）

1. 管理员在微信中发送分享卡片
2. 您点击卡片打开小程序
3. 未登录用户：自动跳转登录页 → 登录后回跳 → 弹出确认弹窗
4. 已登录用户：直接弹出确认弹窗
5. 弹窗显示目标账本名称
6. 点击"加入"完成加入

#### 方式二：暂不加入

点击确认弹窗中的"暂不加入"，不加入该家庭。邀请码在有效期内仍然有效，可重新点击卡片加入。

### 加入后的变化

- 您的历史记录会自动迁移到家庭账本
- 原个人账本自动删除
- 首页显示的是家庭账本的数据
- 家庭成员共享所有账目

### 成员管理

**管理员可看到：**
- 账本名称
- 成员列表（显示真实头像和昵称）
- 邀请码及有效期
- "邀请成员"按钮

**普通成员可看到：**
- 账本名称
- 成员列表
- 不显示邀请码区域和邀请按钮

### 场景说明

| 场景 | 提示 |
|------|------|
| 已是家庭成员再次点击链接 | "你已是该家庭的成员" |
| 邀请码过期 | "邀请已失效，已超过 1 小时" |
| 邀请码已被使用 | "该邀请已被使用" |
| 已在其他家庭 | "你已有其他家庭账本，暂不支持切换" |
| 再次点击自己的邀请链接 | "你已是该账本的管理员" |

## 8. 记录详情

### 查看详情

在首页点击任意一条记录卡片，进入详情页：
- 分类图标和名称
- 金额（支出橙色 / 收入绿色）
- 日期
- 备注（如有）
- 记账人和类型信息

### 查看图片

- 有图片的记录显示"图片 (N)"标题
- 图片以网格形式展示
- 点击图片全屏预览，多张图片可左右滑动

### 删除记录

- **创建者本人：** 显示"删除记录"按钮 → 确认删除
- **其他成员：** 不显示删除按钮

## 9. 版本更新

小程序会在启动时检查是否有新版本：
- 如果新版本已经下载完成，会显示不可取消的更新提示。
- 点击"立即更新"后，小程序会应用更新并重启。
- 如果新版本下载失败，会提示关闭并重新打开小程序，避免继续使用旧版本造成数据或接口不一致。

## 10. 常见问题

### 如何修改头像和昵称？

进入"我的"页 → 点击 ✏️ 按钮 → 编辑头像和昵称 → 保存。

### 如何邀请家人一起记账？

管理员进入"我的" → "家庭" → 点击"邀请成员" → 通过微信分享卡片给家人。

### 如何设置预算？

进入"我的" → "预算管理"，管理员可以设置月度总预算和分类预算。设置后首页和统计页会显示预算使用进度。

### 为什么复制上月预算提示"上月未设置预算"？

说明上一个月份没有可复制的预算。系统不会创建空预算，也不会覆盖当前月份已有预算。

### 为什么分类超支后每次还会提醒？

分类预算达到或超过 100% 后，继续记录该分类支出都会提示超支，帮助家庭成员及时感知该分类已经超预算。总预算超支提醒则只在首次跨线时提示。

### 为什么首页记录按日期分组？

新版首页按具体日期分组，今天和昨天使用相对文案，其余日期显示具体日期。每个分组右侧展示当天收入和支出小计，便于查看每天的消费结构。

### 加入家庭后会丢失之前的记录吗？

不会。个人记录会自动迁移到家庭账本，所有数据保留。

### 图片上传有什么限制？

最多 9 张/条记录，支持拍照和相册选择。家庭成员之间互相可见。

### 为什么看不到对方记账的图片？

请确保双方已加入同一个家庭账本。图片通过云端共享，家庭成员均可查看。

### 如何切换月份查看历史账目？

首页顶部点击 `<` 和 `>` 按钮切换月份，统计页同理。

### 退出登录后数据会丢失吗？

不会。所有数据存储在云端，重新登录后自动恢复。
