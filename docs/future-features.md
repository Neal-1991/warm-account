# 待办功能规划

本文档记录后续计划新增的功能。

## 功能列表

### 1. 语音记账（优先级低）

用户通过语音输入记账内容（如"早餐花了15块"），系统自动识别并填充金额、分类、日期等字段。

**初步思路：**
- 利用微信的语音识别接口（或第三方语音转文字 API）
- 解析自然语言提取关键信息：金额、分类、备注
- 在"记一笔"页面增加语音输入按钮
- 需要 NLP 规则引擎或调用大模型进行语义解析

### 2. 已完成能力

- [已完成 2026-06-15] 预算管理：月度总预算、分类预算、预算进度和超支提醒。
- [已完成 2026-06-23] 客户端版本更新：统一版本号配置，新版本准备完成后强制重启，下载失败时提示关闭并重新打开。
- [已完成 2026-06-25] 首页体验：冷启动加载优化、预算独立刷新、账目按日期分组和当日小计。

### 3. 下一轮优化候选

1. **记录列表分页（优先级中）**  
   当前 `record/list` 每月最多返回 500 条记录。活跃家庭账本长期使用后可能丢失早期记录展示，建议改为按日期 + createdAt 游标分页，并在首页按需加载更多。

2. **环境切换自动化（优先级中）**  
   当前通过手动修改 `config.js` 的 `isTest` 切换 `_test/_prod`，发布前后容易误连环境。建议增加更明确的发布检查或环境构建脚本，开发默认测试环境，上传生产前显式确认。

3. **统一云函数调用封装（优先级低）**  
   `utils/cloud.js` 已有 `callFunction` 封装，但页面仍大量直接使用 `wx.cloud.callFunction`。后续可逐步统一错误处理、loading 关闭和稳定错误码展示。

4. **分类删除/归并体验优化（优先级中）**  
   当前删除有记录的小类只支持归并到父大类或同父其他小类。后续可优化提示文案，或评估跨大类迁移记录能力。

5. **更多功能想法（待探索）**  
   可继续探索周期账单、多人记账提醒、预算复盘、家庭成员记账排行榜、导出 CSV/Excel、账目搜索等功能。
