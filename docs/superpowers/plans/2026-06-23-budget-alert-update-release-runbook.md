# 暖账 3.0.1 上线操作手册

**更新日期：** 2026-07-02  
**版本号：** `3.0.1`  
**项目目录：** `C:\Users\123\git\Ledger\.worktrees\warm-account`

**发布状态：** 已完成生产发布与生产回归。本手册保留为 `3.0.1` 发布记录和后续类似小版本发布参考。

本次只发布昨天和今天改到的功能：

- 复制上月无预算时给出明确提示。
- 分类预算超过 100% 后，每笔该分类支出继续提醒。
- 预算提醒改为非阻塞提示条，约 2 秒后自动回首页。
- 接入小程序强制更新机制。
- 优化首页冷启动加载速度。
- 首页记账记录按日期分组显示，并展示当日收入/支出小计。

不需要重新测试邀请、家庭迁移、分类合并、统计图表、协议隐私等无关功能。

### 3.1 预算相关

只测本次改动点：

1. 选择一个“上月未设置预算、当前月也未设置预算”的月份，点击“复制上月”。
2. 设置某个支出大类预算，例如餐饮 `100 元`，总预算设置高一点，避免总预算干扰。
3. 记账使该分类从 79% 左右跨过 80%。
4. 继续记账到超过 100%。
5. 超过 100% 后，再记一笔同分类支出。

通过标准：

- [x] 复制上月时 loading 正常消失，并提示“上月未设置预算”。
- [x] 当前月份不会被创建空预算或假预算。
- [x] 首次跨过 80% 只提醒一次。
- [x] 首次达到或超过 100% 时提示分类预算超支。
- [x] 已超支后继续记同分类支出，仍显示分类超支提醒。
- [x] 提示条不是弹窗，没有遮罩和“知道了”按钮。
- [x] 提示约 2 秒后自动回首页，首页预算卡和最新账目刷新。
- [x] 收入记账不触发预算提醒。

家庭账本只做一个最小确认：

- [x] A 使某分类超过 100% 后，B 继续记同分类支出也能收到超支提醒。

### 3.2 首页加载与日期分组

准备几条测试记录：

- 今天一条支出。
- 昨天一条支出。
- 4～5 天前一条支出。
- 同一天再补一条收入，用来检查小计。

测试步骤：

1. 彻底关闭小程序后重新打开。
2. 观察首页记账记录是否比之前更快显示。
3. 查看首页记录日期分组。
4. 点击分组内任意记录进入详情页。

通过标准：

- [x] 有本地登录态时，首页记录不再等约 10 秒才出现。
- [x] 首页没有明显重复刷新、闪烁或加载两遍。
- [x] 今天显示“今天”，昨天显示“昨天”。
- [x] 4～5 天前显示具体日期，例如 `6月21日`，不显示“4天前/5天前”。
- [x] 同一天有收入和支出时，日期标题右侧显示当日收入/支出小计。
- [x] 分组内记录卡片不重复显示日期，但点击仍能进入详情页。
