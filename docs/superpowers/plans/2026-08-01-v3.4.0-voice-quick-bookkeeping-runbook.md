## 1. 改动概览

### 1.1 新增功能

| # | 功能 | 说明 |

## 3. 配置腾讯云 ASR 服务（**首次上线必做**）

语音记账依赖腾讯云一句话识别（SentenceRecognition）服务，**首次上线必须先开通并配置密钥**。

### 3.1 开通 ASR 服务

1. 登录 [腾讯云语音识别控制台](https://console.cloud.tencent.com/asr)
2. 确认已开通「一句话识别」服务
3. 确认账户有可用额度（一句话识别每月有免费额度，超出按次计费）

### 3.2 创建 API 密钥

1. 登录 [腾讯云 API 密钥管理](https://console.cloud.tencent.com/cam/capi)
2. 如已有可用密钥，直接使用
3. 如需新建：
   - 新建用户 →「自定义创建」→「编程访问」
   - 关联策略：`QcloudASRFullAccess`（仅语音识别权限，最小权限原则）
   - 记下 `SecretId` 和 `SecretKey`

### 3.3 在 CloudBase 配置云函数环境变量

1. 登录 [CloudBase 控制台](https://console.cloud.tencent.com/tcb)
2. 选择环境（与小程序对应的 `cloud1` 环境）
3. 云函数 → 找到 `voice-entry`（**部署完成后才能配置**，见第 4 节）
4. 环境变量 → 添加：
   - `TENCENT_SECRET_ID` = 你的 SecretId（ASR 用，腾讯云 API 密钥）
   - `TENCENT_SECRET_KEY` = 你的 SecretKey（ASR 用，腾讯云 API 密钥）
   - `TOKENHUB_API_KEY` = 你的 TokenHub API Key（Hy3 用，在 TokenHub 控制台「API Key 管理」页面创建）
5. 保存后云函数会自动重载

> **安全提示：** 密钥只存在云函数环境变量，不会进入小程序包、Git 仓库或客户端日志。
> ASR 与 Hy3 使用独立的鉴权方式：ASR 走腾讯云 TC3-HMAC-SHA256 签名（SecretId/SecretKey），Hy3 走 TokenHub OpenAI 兼容接口（Bearer Token）。

### 3.4 创建数据库集合（幂等用）

在 CloudBase 数据库新建集合：

- `voiceRequests_prod`（生产环境，**必建**）
- `voiceRequests_test`（测试环境，如需走测试环境验证则必建）

字段会自动写入，无需手动建字段。首次调用 batchCreate 时自动产生记录。

**为两个集合创建唯一索引（必做，且必须在首次写入前创建）：**

| 集合 | 索引字段 | 说明 |
|---|---|---|
| `voiceRequests_prod` | `openId` + `requestId`（组合唯一） | 防止同一用户同一请求重复写入幂等记录 |
| `voiceRequests_test` | `openId` + `requestId`（组合唯一） | 同上 |

**操作顺序（严格按此顺序）：**

1. 在 CloudBase 控制台创建 `voiceRequests_prod` 集合（此时为空）
2. 立即进入集合 →「索引管理」→ 创建组合唯一索引：
   - 字段1：`openId`（升序）
   - 字段2：`requestId`（升序）
   - 是否唯一：**是**
3. 对 `voiceRequests_test` 重复步骤 1-2
4. 之后才进行真机测试，触发首次 batchCreate 写入

> **为什么必须在写入前建索引：** CloudBase 数据库创建索引不依赖数据存在，空集合也可以建。但**强烈建议在写入数据前就建好唯一索引**——如果等数据有了再建，已存在的重复数据会导致建索引失败，需要先手动去重。
>
> **容错说明：** v3.4.0 修订后，`batchCreate` 的幂等首查改为 `try/catch` best-effort。集合未创建时不会让功能整体失败，会降级为"不做幂等、直接写入"并打 `console.warn` 告警，但**无法实现严格幂等**，重复点击可能产生重复记录。因此集合和索引必须在上线前创建。

### 5.3 配置权限声明和隐私协议

`miniprogram/app.json` 已配置以下权限相关字段（v3.4.0 已内置）：

```json
{
  "permission": {
    "scope.record": {
      "desc": "用于语音记账功能，识别你的语音内容生成记账草稿"
    }
  },
  "requiredPrivateInfos": [],
  "__usePrivacyCheck__": true,
  "__privacySetting__": {
    "privacyContractName": "用户隐私保护指引",
    "apis": ["scope.record"]
  }
}
```

**关键说明：**

- `permission.scope.record`：声明麦克风权限用途
- `__usePrivacyCheck__`：启用微信新隐私协议检查（基础库 2.32.3+ 必须开启，否则敏感 API 报 `api scope is not declared in the privacy agreement` 错误）
- `__privacySetting__.apis`：声明哪些 API 需要走隐私协议
- 代码里在进入语音记账页 onLoad 时先调 `wx.requirePrivacyAuthorize()` 让用户同意隐私协议，再用 `wx.getSetting` 检查麦克风权限状态：已授权则标记就绪；从未问过则主动调 `wx.authorize` 请求授权；拒绝过则等用户按住按钮时引导去设置。这样用户按住说话时权限已就绪，避免 touchstart 期间异步弹窗的时序问题。

> 检查 `project.config.json` 的 `setting` 不限制麦克风权限（默认不限制）。
> 首次进入语音记账页时，会依次弹出：隐私协议同意弹窗 → 麦克风授权弹窗（onLoad 阶段），授权后按住按钮即可直接录音。

### 12.4 Hy3 AI Provider 说明

- Provider：`hy3`（腾讯混元大模型，旧版 `hunyuan-turbo` 等已于 2026-06-22 下线，TokenHub 现仅提供 `hy3` 服务）
- 调用方式：腾讯云 TokenHub OpenAI 兼容接口（`https://tokenhub.tencentmaas.com/v1/chat/completions`），Bearer Token 鉴权
- 鉴权：独立的 `TOKENHUB_API_KEY` 环境变量（与 ASR 的 `TENCENT_SECRET_ID`/`TENCENT_SECRET_KEY` 分离）
- 前置条件：腾讯云 TokenHub 控制台已开通 `hy3` 模型（[在线推理](https://console.cloud.tencent.com/tokenhub/inference) 页面开启免费体验+后付费），并创建 API Key
- 失败处理：超时 15 秒，最多重试 1 次（仅修复 JSON 格式）
- 成本控制：规则优先解析，仅规则无法覆盖时调用 Hy3

### 12.6 常见问题排查

| 现象 | 可能原因 | 排查方法 |
|---|---|---|
| 录音后提示「ASR 服务未配置」 | 环境变量未配置 | 检查 CloudBase 控制台 voice-entry 环境变量 `TENCENT_SECRET_ID`/`TENCENT_SECRET_KEY` |

| 提示「混元调用失败」+ errorCode `unauthorized` | API Key 无效 | 重新在 TokenHub [API Key 管理](https://console.cloud.tencent.com/tokenhub/apikey) 页面创建 |
| 提示「混元调用失败」+ errorCode `model_not_found` | `hy3` 模型未开通 | 前往 [TokenHub 在线推理](https://console.cloud.tencent.com/tokenhub/inference) 开启免费体验+后付费 |
| 提示「该模型已下线」 | 代码用了旧模型名 `hunyuan-turbo` 等 | v3.4.0 已迁移到 `hy3`，重新上传 voice-entry 云函数 |
| 提示「cloud.ai 不可用」 | 历史残留（旧版用 cloud.extend.AI） | v3.4.0 已改为 TokenHub OpenAI 兼容接口，此错误不再出现；若仍出现说明部署了旧代码，重新上传 |
| Hy3 返回非 JSON | AI 输出不稳定 | 已有 1 次修复重试，仍失败会回退规则结果 |
| 确认按钮置灰 | 有 item 未选分类或有 warnings | 展开每项检查 needsReview 标签 |
| 提示「请求过于频繁，请稍后再试」 | 10 秒内同一用户重复请求 ASR（`checkRateLimit` 限制） | 等待 10 秒后重试；如持续出现检查是否 onStop 被重复触发 |
| 写入失败「BATCH_ROLLED_BACK」 | 数据库写入异常 | 查看云函数日志，检查 records_prod 权限 |
| 写入失败「PARTIAL_ROLLBACK_INCOMPLETE」 | 补偿删除未完成 | 记录 orphanIds，人工核对并清理 |

### 12.7 隐私与合规要点

- **原始音频：** 临时上传到 CloudBase 云存储，ASR 完成后立即 `cloud.deleteFile` 删除，不长期保存
- **识别文本：** 仅在本次流程内保留，不做跨页面持久化；最终记录不保存完整 transcript
- **来源元数据：** 仅保存 `source`、`voiceRequestId`、`voiceItemId` 三个最小字段
- **ASR 密钥：** 通过云函数环境变量注入，不进入小程序包、Git 仓库或客户端日志
- **内容安全：** 解析出的 remark 仍走现有 `msgSecCheck` 检测
