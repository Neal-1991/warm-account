### 3.1 分类图标录入

在测试环境分别验证支出和收入新增大类：

- 支出输入 `买菜`，应推荐 `icon_grocery_bag`。
- 支出输入 `话费`，应推荐 `icon_phone_bill`。
- 支出输入 `医疗`，应推荐 `icon_medical`。
- 支出输入 `汽车`，应推荐 `icon_vehicle`。
- 收入输入 `退款`，应推荐 `icon_wallet_refund`。
- 收入输入 `报销` 或 `医保报销`，应推荐 `icon_receipt_return`。
- 收入输入 `红包礼金`，应推荐 `icon_red_packet_money`。
- 收入输入 `奖金`，应推荐 `icon_award_money`。
- 收入输入 `废品回收`，应推荐 `icon_recycle_money`。
- 输入未知名称，应推荐 `icon_tag_default`。

验收点：

- 新增/改名大类弹层不出现 emoji 输入主入口。
- 手动切换图标后保存，列表展示手动选择的图标。
- 首页记录只显示用户分类名，不显示图标语义名，也不出现图标内中文文字。
- 小类沿用父大类图标。

### 3.2 历史 emoji 兼容

在测试环境用临时大类或存量数据验证：

- `医保报销` + 收入 + `💊` 应显示 `icon_receipt_return`，不能显示医疗支出图标。
- `汽车` + 支出 + `🚗` 应显示 `icon_vehicle`。
- `🚉/🚆/🚄/🚅` 应归一到交通图标。
- `➕/📦` 应归一到默认图标。
- 无法判断语义的历史 emoji 应继续兜底显示，不做错误替换。

### 3.3 主题颜色弹层滚动

在小屏模拟器和至少一台真机验证“我的 - 主题颜色”：

- 底部弹层标题固定，主题列表可以上下滚动。
- 可以看到并选择全部主题选项。
- 底部安全区不遮挡最后一个主题。
- 点击遮罩可以关闭弹层。
- 点击面板内部不会误关闭弹层。
- 选择主题后，分类图标容器颜色跟随主题变化，图标主体仍清晰。

### 3.4 记录编辑

在测试环境至少验证：

- 新增一条支出记录和一条收入记录，从详情页进入编辑。
- 修改金额、备注、日期和分类后保存，详情页返回后显示最新数据。
- 将一条支出切为收入，确认分类被清空，必须重新选择收入分类才能保存。
- 对一条带图片记录执行“保留旧图片 + 新增图片”和“删除旧图片”两种保存。
- 使用普通成员账号打开他人记录，确认不显示编辑入口；账本所有者可编辑家庭成员记录。
- 新增记账仍能成功，新增支出仍可触发现有预算提醒；编辑保存不弹预算提醒浮层。

### 3.5 测试反馈修复

在测试环境至少验证：

- 打开记一笔支出/收入，未选分类时分类行不显示默认 emoji；选中分类后才显示图标。
- 预算页大类预算行显示“移除”；点击后有确认弹框，确认后只改当前草稿，保存预算后才生效。
- 首页从其他 tab 切回时预算卡不闪成未设置；新增/编辑/删除本月支出后预算卡最终刷新。
- 分类管理页支出/收入大类可上移/下移；同一大类下小类可上移/下移；小类不出现跨大类迁移入口。

### 3.6 内容安全审核修复

在测试环境至少验证：

- 普通无备注记录、普通备注记录和带普通图片记录均可保存。
- 新增/编辑记录备注输入明显违规测试文本时，保存失败并提示“内容含违规信息，请修改后再试”。
- 记一笔分类弹层新增大类/小类时，普通名称可保存，明显违规测试名称被拒绝。
- 分类管理页新增/改名大类/小类时，普通名称可保存，明显违规测试名称被拒绝。
- 模拟内容安全接口异常或弱网超时时，记录和分类均不保存，并提示“内容安全检测暂不可用，请稍后再试”。
- 前端提示不展示 label、命中规则、traceId 等检测细节。
- 记录保存被内容安全拦截后，首页、详情、统计和预算页不出现半写入脏数据；本次新上传但未入库的图片被清理，旧图片不被误删。

## 9. 停止发布或回滚条件

出现以下任一情况，应停止发布或回滚到上一稳定版本：

- 分类图标大面积空白或图片加载失败。
- 历史存量大类被错误映射，例如 `医保报销` 显示为医疗支出图标。
- 新增大类保存后首页不显示用户分类名，或显示了图标语义名。
- 新增/改名大类仍暴露 emoji 输入主入口。
- 主题颜色弹层在真机小屏无法滚动到底部。
- 记录编辑保存失败、保存后详情/首页不刷新，或普通成员可编辑他人记录。
- 分类排序后记一笔选择器顺序混乱，或小类出现跨大类迁移。
- 预算大类移除绕过确认，或未保存就写入云端。
- 首页预算卡在切 tab 后持续显示错误的未设置状态。
- 生产体验版出现登录、首页加载或记账保存阻塞。
- 记录备注、记录图片或分类名称可绕过内容安全检测写入。
- 内容安全接口异常时仍允许保存用户内容。
- 内容安全失败时前端暴露 label、命中规则、traceId 等检测细节。
