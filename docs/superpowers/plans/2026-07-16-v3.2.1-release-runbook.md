### 3.2 v3.2.1 修复项验收

#### TC-301 抽屉金额完整显示（v3.2.1 第三轮修复）

**问题位置**：统计页点击饼图图例大类 → 底部弹出抽屉 → 抽屉内每条记录的金额（如 `-¥12.34`）小数部分被右边框裁切。

- 统计页点击任一大类打开抽屉。
- 找一条金额有两位小数的记录（如 12.34），确认「-¥12.34」完整显示，小数部分不被裁切。
- 测试长分类名场景（如「餐饮美食家庭聚餐」），分类名应省略号截断，金额仍完整显示在右侧。
- 测试长备注场景，备注省略号截断，金额不受影响。

> **根因说明（三轮）**：
> - 第一轮给 `.drawer-record-amount` 加 `flex-shrink: 0`——未解决，因为 `.drawer-record-info` 的 `min-width: 0` 在 `<scroll-view>` 内部 flex 渲染中不可靠，分类名文本撑宽 info 把金额挤出容器。
> - 第二轮给 `.drawer-record-info` 加 `overflow: hidden`，给 `.drawer-record-category` 加 `text-overflow: ellipsis`——仍未解决，`min-width: 0` + `overflow: hidden` 组合在微信小程序 scroll-view 中不生效。
> - 第三轮将 `.drawer-record-info` 改为 `flex: 1 1 0` + `width: 0` + `overflow: hidden`——`flex: 1 1 0` + `width: 0` 是最强力的 flex 收缩组合，强制 flex item 从 0 宽度开始扩展，完全忽略内容宽度，真正解决收缩问题。

**问题位置**：记一笔页 → 点击分类选择器 → 弹出底部「选择分类」浮层 → 浮层底部的「确定」按钮在全面屏机型被 Home Indicator 遮挡。

> **根因说明（三轮）**：
> - 第一轮和第二轮误解问题位置，改了 `add.wxml` 的提交按钮（`.submit-btn`），但实际问题是 `category-picker` 组件的「确定」按钮（`.confirm-btn`）。

## 9. 停止发布或回滚条件

出现以下任一情况，应停止发布或回滚到上一稳定版本（生产 3.1.0）：

### v3.2.1 特定回滚条件

- 抽屉金额仍被裁切。
- 抽屉内图片标识位置错乱或不显示。
- 提交按钮在任一机型被裁切。
- 提交按钮 disabled 状态视觉异常（如文字颜色不是白色）。
- 提交按钮点击无响应（view 未正确绑定事件）。
- 首页加载出现新的异常 toast。
- 首页在 session 过期时无法正确清空数据跳转登录。
- 首页在网络异常时未出现任何提示（静默失败）。

### v3.2.0 既有回滚条件

- 统计页点击图例无响应，或抽屉无法滑出。
- 抽屉内记录列表为空但图例显示有金额。
- 抽屉内点击记录无法跳转详情页。
- 抽屉关闭后再打开，记录数据丢失或闪烁。
- 抽屉打开时发起了额外的云函数请求（违反设计）。
- 非全面屏机型上按钮位置发生漂移。
- 预算提醒浮层与提交按钮重叠。
- 表单最后一项被 fixed 按钮遮挡。

### v3.1.0 既有回滚条件

- 分类图标大面积空白或图片加载失败。
- 历史存量大类被错误映射，例如 `医保报销` 显示为医疗支出图标。
- 新增大类保存后首页不显示用户分类名，或显示了图标语义名。
- 新增/改名大类仍暴露 emoji 输入主入口。
- 主题颜色弹层在真机小屏无法滚动到底部。
- 记录编辑保存失败、保存后详情/首页不刷新，或普通成员可编辑他人记录。
- 分类排序后记一笔选择器顺序混乱，或小类出现跨大类迁移。
- 预算大类移除绕过确认，或未保存就写入云端。
- 首页预算卡在切 tab 后持续显示错误的未设置状态。
- 生产体验版出现登录、首页加载或记账保存阻塞。
- 记录备注、记录图片或分类名称可绕过内容安全检测写入。
- 内容安全接口异常时仍允许保存用户内容。
- 内容安全失败时前端暴露 label、命中规则、traceId 等检测细节。

### 回滚操作

1. 在微信公众平台 → 版本管理 → 回退到上一稳定版本（生产 3.1.0）。
2. 将 `miniprogram/utils/config.js` 切回测试环境继续修复：

```js
const isTest = true
```

3. 云函数如已上传生产环境且出现兼容性问题，可在微信云开发控制台 → 云函数 → 版本管理中回退到上一版本。如无版本管理，需重新上传上一稳定版本代码。
4. 修复后重新走第 1 节开始的完整流程，版本号递增为 `3.2.2`。
