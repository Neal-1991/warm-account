### TC-011: 饼图显示
**前置条件：** 当月有支出记录

1. 点击底部Tab"统计"

**预期结果：**
- [x] 顶部显示月份选择器
- [x] 中间显示环形饼图（已修复：Canvas 2D API + observer 延迟初始化）
- [x] 饼图按**大类**显示（如"餐饮"、"交通"），而非小类
- [x] 右侧/下方显示图例列表

**设计变更（2026-05-09）：** 统计维度从小类改为大类聚合

**修复记录（2026-05-08）：**
```
根因1：echarts.min.js是浏览器版，echarts.init()需要canvas节点的getContext和addEventListener
      旧版API的wx.createCanvasContext返回的CanvasContext没有这些方法
根因2：canvas缺少id属性，#pie-chart选择器查不到元素
根因3：ecChart初始值null，ready()只触发一次错过初始化
修复：canvas加type="2d"和id；用select().fields({node:true})获取canvas节点；
     补上addEventListener/removeEventListener空函数；添加observer支持延迟初始化
```

## 十一、已修复问题记录

### 统计页饼图不显示（2026-05-08 已修复）
**根因：** echarts.min.js 是浏览器版，依赖 DOM API；Canvas 1.0 的 wx.createCanvasContext 返回对象不支持。
**修复：** 改用 Canvas 2D + WxCanvas 包装器 + echarts.setCanvasCreator()，支持 touch 事件。
**相关文件：** `components/ec-canvas/ec-canvas.wxml`、`ec-canvas.js`

### 已是成员点击邀请链接提示错误（2026-05-10 已修复）
**问题：** B 加入家庭后再次点击邀请链接，显示"邀请已被使用"而非"你已是成员"
**根因：** `validateInviteCode` 不传 `openId`，无法区分 code-used-by-me 和 code-used-by-other
**修复：** `family.js` 传递 `openId`；云函数在 `inviteCodeUsedBy` 存在时先检查是否已是成员
**相关文件：** `miniprogram/pages/family/family.js`、`cloudfunctions/book/index.js`

### 首页记录图标和分类都显示餐饮（2026-05-10 已修复）
**问题：** 不管记账选的什么分类，首页记录列表的图标和分类名都是 📝/餐饮
**根因：** `index.js` loadData() 硬编码 icon='📝' categoryName='餐饮'
**修复：** 改为先调用 category 云函数构建 categoryId→{大类名, 图标} 映射，再填充记录卡片
**相关文件：** `miniprogram/pages/index/index.js`

### 加入家庭后统计页出现未分类（2026-05-10 已修复）
**问题：** B 加入 A 的账本后，A 和 B 看统计页都有一条分类显示"未分类"
**根因：** `book/index.js` join action 中 `col=collectionName('books')` 被误用于查询/修改 categories 集合（4处），B 的小类从未迁移
**修复：** 新增 `catCol=collectionName('categories')`，categories 相关操作全部改用 `catCol`
**相关文件：** `cloudfunctions/book/index.js`

### 头像选择后无法持久保留（2026-05-28 已修复）
**问题：** 在"我的"页选择微信头像后退出重新登录，头像消失。
**根因：** `chooseAvatar` 返回本地临时路径（`wxfile://tmp_xxx`），存到云端后下次登录路径已过期。
**修复：** mine.js 保存时检测临时路径，先上传到云存储存 cloud file ID；login 云函数返回头像时 `cloud://` 路径转 temp URL。
**相关文件：** `miniprogram/pages/mine/mine.js`、`cloudfunctions/login/index.js`

### 已是成员点击邀请链接提示邀请无效（2026-05-28 已修复）
**问题：** B 加入家庭后再次点击分享链接，提示"邀请无效"而非"你已是成员"。
**根因：** join 成功后清空了 `inviteCode` 字段，`validateInviteCode` 按码查不到账本。
**修复：** join 后不再清空 `inviteCode`，保留码值供验证。
**相关文件：** `cloudfunctions/book/index.js`

### 昵称更新后账本名称未同步（2026-05-28 已修复）
**问题：** 修改昵称后，账本名称仍为旧昵称+"的账本"。
**根因：** `updateProfile` 只更新了 `members` 集合，未更新 `books` 集合的账本名。
**修复：** mine.js 传 `bookId`；login 云函数检测所有者后同步更新账本名。
**相关文件：** `miniprogram/pages/mine/mine.js`、`cloudfunctions/login/index.js`
