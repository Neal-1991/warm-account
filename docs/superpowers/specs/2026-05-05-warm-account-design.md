# 暖账 - 家庭协作记账小程序 设计文档

> 日期：2026-05-05
> 状态：已确认

---

## 1. 产品概述

**产品名称**：暖账
**产品定位**：面向家庭用户的微信小程序，专注于家庭日常收支记录、财务管理和家庭协作记账。
**核心价值**：让家庭成员共同参与记账，提升财务透明度，增进家庭协作。

---

## 2. 核心功能范围（V1）

### 2.1 登录策略
- **游客模式 + 按需登录**：用户首次访问直接进入首页，可浏览 Tab 栏和空状态界面；需要进行记账、家庭管理等操作时才引导登录
- 登录时展示用户协议和隐私政策供用户阅读并同意
- 登录方式：微信一键登录（获取昵称、头像）
- 登录后返回触发登录的来源页面

### 2.2 账本模型
- **不区分个人账本与家庭账本**，统一为账本概念
- **一人一个账本**：一个用户只能拥有一个账本
- **账本创建**：新用户登录后自动创建一个空账本，账本名称默认取自微信昵称+"的账本"
- **婚后合并**：用户 A 邀请用户 B 加入时，B 的历史账目迁移到 A 的账本，形成统一的家庭账本
- **所有成员可见所有账目**：V1 阶段所有家庭成员都能看到账本内的所有账目记录

### 2.3 家庭成员管理
- **邀请码制**：家庭管理员生成邀请码，新成员输入邀请码加入
- **管理员权限**：管理员可更新或删除其他成员的记账明细
- **普通成员权限**：可新增账目、查看所有账目，无删除/修改他人账目权限

## 3. 数据模型

- **分类结构：层级分类 + 类型区分**

  - 小类：在各大类下，用户可新增、改名、删除（有记录时归并到父类或同父其他子类）
  - 记账可选大类或小类

## 5. 界面设计

### 5.1 首页（月度账目流）
**方案：分区卡片式**

- 顶部：月份选择器（可切换月份）
- 中间：月度汇总卡片（渐变色背景，显示结余/支出/收入）
- 下方：近期账目列表（卡片形式，每条账目显示图标+分类+备注+金额+时间+记账人）
- 右下角：悬浮 "+" 按钮，新增账目

### 5.2 统计页
**方案：按大类占比饼图**

- 月度支出分类饼图（ECharts 环形图），按**大类**（餐饮、交通、购物等）聚合
- 小类金额汇总到所属大类，避免碎片化
- 顶部可切换月份
- 饼图旁边显示分类明细列表（大类名+金额+占比），按金额降序排列

### 5.3 新增账目页（一页完成）
**必填字段：**
- 类型（支出/收入切换）
- 金额
- 分类（点击弹出层级分类弹窗，可选大类或小类）
- 日期（默认当天，可修改）
- 记账人（系统自动填充，当前用户）

**选填字段：**
- 备注
- 上传图片（最多 9 张，上传至微信云存储后存入 cloud file ID，路径前缀 test/ 或 prod/）

**分类管理入口：**
- 在分类选择弹窗中提供"管理"入口，跳转独立分类管理页
- 分类管理页支持：大类/小类的新增、改名（含 emoji）、删除
- 弹窗内支持快速添加大类（含 emoji 输入）和添加小类

### 5.4 我的页
**结构：**
- 头像 + 昵称（可编辑）
- 家庭入口（卡片形式，显示家庭名称）
- 关于（跳转到关于页）
- 退出登录

### 5.5 家庭详情页
**结构：**
- 家庭名称（管理员可编辑）
- 成员列表（头像+昵称+角色+移除按钮，移除功能开发中）
- 邀请成员按钮（通过微信分享卡片发送邀请码）
- 确认加入弹窗（被邀请人点击卡片后弹出）
- 提示弹窗（邀请过期/已使用/已在其他家庭等异常情况）

### 5.6 关于页
**内容：**
- 暖账 logo + 名称
- 版本号
- 用户协议链接
- 隐私政策链接

### 5.7 记录详情页
**功能：** 点击首页记录卡片进入，查看单条记录的完整信息

**布局：**
- 顶部：分类图标 + 名称、金额（支出橙色/收入绿色）、日期
- 备注区（如有备注）
- 图片网格：最多 9 张，点击调用 `wx.previewImage` 全屏浏览
- 记账信息：记账人、类型（支出/收入）
- 删除按钮：仅记录的创建者可见，点击确认后删除并返回首页

## 6. 交互流程

### 6.1 登录流程
1. 用户打开小程序 → 直接进入首页（Tab 栏可见，页面展示空状态）
2. 用户浏览首页、统计页、我的页，了解小程序功能
3. 用户进行需要登录的操作时（点击"+"记一笔、进入家庭页、编辑个人信息等），自动跳转登录页
4. 登录页展示用户协议 + 隐私政策 + "微信一键登录"按钮
5. 用户点击登录 → 微信授权 → 获取 openId、昵称、头像
6. 自动创建账本（或加入已有账本） → 返回触发登录的来源页面
7. 游客模式下不发起云函数请求，仅展示空状态 UI

### 6.2 邀请加入流程

**A 端（管理员）：**
1. 管理员进入"家庭详情"页
2. 点击"邀请成员"按钮 → 云函数生成6位邀请码（1小时有效，一次性使用）
3. 触发微信分享面板，邀请码嵌入分享卡片 `path` 参数
4. 管理员选择微信好友发送卡片

**B 端（被邀请人）：**
1. B 在微信聊天中点击分享卡片
2. 小程序打开 family 页，携带 `inviteCode` 参数
3. 判断登录状态：
   - 未登录 → 暂存邀请码到 Storage → 跳转登录页 → 登录成功后回跳 family 页
   - 已登录 → 继续
4. 云函数验证邀请码：
   - 有效 → 弹确认窗，显示目标账本名称
   - 已过期/已被使用/不存在 → 弹提示窗，显示对应错误信息
5. B 选择：
   - "加入" → 验证通过 → B 的历史账目迁移到家庭账本 → B 的原账本删除 → 加入成功
   - "暂不加入" → 弹窗关闭，邀请码仍有效（1小时内可重新点击卡片）
6. B 在1小时内想加入时，需重新点击微信聊天中的分享卡片

**全场景处理：**

| B 状态 | 码状态 | 处理 |
|--------|--------|------|
| 未登录 | 有效 | 暂存 → 登录 → 回跳 → 弹确认窗 |
| 未登录 | 过期/已用/无效 | 暂存 → 登录 → 回跳 → 提示对应错误 |
| 已登录独有账本 | 有效 | 弹确认窗 |
| 已登录独有账本 | 过期/已用/无效 | 提示对应错误 |
| 已是该家庭成员 | 已被使用 | 提示"你已是该家庭账本的成员" |
| 已是其他家庭成员 | 有效 | 提示"已有其他家庭，暂不支持切换" |
| 已是管理员 | 有效 | 提示"你已是该账本管理员" |

### 6.3 新增账目流程
1. 点击首页悬浮 "+" 按钮
2. 进入"记一笔"页面
3. 选择类型（支出/收入切换，切换后重新加载对应分类）
4. 点击分类区域 → 弹出层级分类弹窗（大类网格 + 小类列表 + "记在XX下"大类入口）
5. 选择大类后可选：
   - 点击"记在「XX」下"直接记账在大类
   - 选择下方小类记账在小类
6. 填写金额（键盘输入）
7. 选择日期（默认当天）
8. 选填：备注、图片（最多9张）
9. 点击"提交" → 保存到云数据库 → 返回首页刷新列表

**分类管理入口：**
- 在分类选择弹窗中提供"管理"入口，跳转独立分类管理页
- 分类管理页支持大类/小类的新增、改名（含 emoji）、删除（有记录时归并）

## 7. 技术方案

### 7.1 技术栈
- **前端**：微信小程序原生框架（ECharts 位于主包但通过 `lazyCodeLoading` 按需注入组件）
- **后端**：微信云开发（云函数）
- **数据存储**：云数据库（测试环境 / 生产环境使用不同集合后缀区分 `_test` / `_prod`，通过 `config.js` 切换）+ 云存储（图片文件）
- **图表**：ECharts for 微信小程序

### 7.2 云函数列表
| 云函数 | 说明 |
|--------|------|
| login | 微信登录 + 自动创建账本 + 成员资料管理 + 自动初始化/迁移分类 |
| book | 账本 CRUD、邀请码生成/验证/加入 |
| record | 账目 CRUD（增删改查） |
| category | 分类列表/新增大类+小类/改名/删除（含记录归并）/存量迁移 |
| init-database | 初始化账本默认分类（每账本独立副本，支出16大类+收入7大类，并行创建）+ updateSystemPresets（生产部署前更新 bookId=null 预设） |
| init-collections | 列出所需数据库集合 |
| clear-test-data | 清理测试数据（开发用） |

## 8. 关键决策汇总

| 问题 | 决策 |
|------|------|
| 账本模型 | 不区分个人/家庭；一人一个账本；婚后合并时历史账目迁移到家庭账本 |
| 成员可见性 | V1 所有成员可见所有账目 |
| 成员记账权 | 所有成员可记账；管理员可删除/修改他人账目（**实现中**） |
| 成员移除 | 管理员可移除成员（**移除功能开发中**） |
| 成员加入方式 | 微信分享卡片邀请制（邀请码嵌入分享路径，一次性有效，1小时过期） |
| 分类模型 | 层级分类 + type字段区分expense/income；每账本独立副本（isSystem标记预置）；大类/小类均可新增、改名、删除（预置不可删）；记账可选大类或小类 |
| 收入分类 | V1 实现完整的收入分类（工资/公积金/投资/副业兼职/闲置转卖/医疗报销/其他），与支出分类并列支持 |
| 首页布局 | 分区卡片式 |
| 新增入口 | 首页右下角悬浮按钮 |
| 账目录入 | 一页完成 |
| 分类选择 | 弹窗形式 + 层级交互 |
| 底部导航 | 3 Tab（首页/统计/我的）|
| 隐私协议 | 登录页展示《用户协议》和《隐私政策》 |
| 统计维度 | 按大类聚合的占比饼图（支出 only） |
| 用户资料持久化 | 服务端 members 集合存储头像昵称，登录时优先读取云端数据 |
| 分类合并 | 加入家庭时按大类名称+小类名称匹配合并；大类记账记录自动重映射 categoryId；无冲突小类迁移时重映射 parentId；自定义大类完整迁移 |
