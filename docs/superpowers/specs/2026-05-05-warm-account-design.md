# 暖账 - 家庭协作记账小程序 设计文档

> 日期：2026-05-05
> 状态：已确认

---

## 1. 产品概述

**产品名称**：暖账
**产品定位**：面向家庭用户的微信小程序，专注于家庭日常收支记录、财务管理和家庭协作记账。
**核心价值**：让家庭成员共同参与记账，提升财务透明度，增进家庭协作。
**对外简介建议**：暖账是一款面向小家庭的协作记账小程序，支持家庭成员共同记录收支、管理分类与预算、查看消费结构，并通过邀请码共享账本，让日常花销更清楚、更好商量。

---

## 2. 核心功能范围（V1）

### 2.1 登录策略
- **游客模式 + 按需登录**：用户首次访问直接进入首页，可浏览 Tab 栏和空状态界面；需要进行记账、家庭管理等操作时才引导登录
- 登录时展示用户协议和隐私政策供用户阅读并同意
- 登录方式：微信一键登录（获取昵称、头像）
- 登录后返回触发登录的来源页面

### 2.2 账本模型
- **不区分个人账本与家庭账本**，统一为账本概念
- **一人一个账本**：一个用户只能拥有一个账本
- **账本创建**：新用户登录后自动创建一个空账本，账本名称默认取自微信昵称+"的账本"
- **婚后合并**：用户 A 邀请用户 B 加入时，B 的历史账目迁移到 A 的账本，形成统一的家庭账本
- **所有成员可见所有账目**：V1 阶段所有家庭成员都能看到账本内的所有账目记录

### 2.3 家庭成员管理
- **邀请码制**：家庭管理员生成邀请码，新成员输入邀请码加入
- **管理员权限**：管理员可更新或删除其他成员的记账明细
- **普通成员权限**：可新增账目、查看所有账目，无删除/修改他人账目权限

## 3. 数据模型

### 3.1 账本（Book）
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | ObjectId | 账本ID |
| name | String | 账本名称 |
| ownerId | String | 创建者（管理员）OpenId |
| memberIds | Array | 成员 OpenId 列表 |
| inviteCode | String | 当前邀请码（6位数字） |
| inviteCodeExpire | Date | 邀请码过期时间 |
| inviteCodeUsedBy | String | 邀请码使用者 OpenId（一次性标记） |
| categorySchemaVersion | Number | 当前账本分类结构版本；仅在当前版本分类完整写入后更新 |
| joinMigration | Object | 家庭加入内部迁移状态；保存邀请人、源账本、阶段、分类映射计划和游标，完成后删除 |
| joinTargetBookId | ObjectId | 源账本正在合并到的目标账本 ID；迁移期间用于阻止账目/分类写入 |
| createdAt | Date | 创建时间 |
| updatedAt | Date | 更新时间 |

### 3.2 账目（Record）
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | ObjectId | 账目ID |
| bookId | ObjectId | 所属账本ID |
| type | String | "expense" / "income" |
| amount | Number | 金额（分） |
| categoryId | ObjectId | 分类ID |
| date | Date | 记账日期 |
| remark | String | 备注（选填） |

| createdBy | String | 记账人 OpenId |
| createdByName | String | 记账人昵称 |
| createdAt | Date | 创建时间 |
| updatedBy | String | 最近修改人 OpenId |
| updatedByName | String | 最近修改人昵称 |
| updatedAt | Date | 更新时间 |

### 3.3 分类（Category）
- **分类结构：层级分类 + 类型区分**
  - 大类：按 `type` 区分 expense/income，每账本独立副本，用户可新增、改名、删除（自建可删，初始预置不可删）
  - 小类：在各大类下，用户可新增、改名、删除（有记录时归并到父类或同父其他子类）
  - 记账可选大类或小类

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | ObjectId | 分类ID |
| parentId | ObjectId | 父分类ID（顶级大类为 null） |
| name | String | 分类名称 |
| icon | String | emoji 图标 |
| order | Number | 排序 |
| type | String | "expense" / "income" |
| isVisible | Boolean | 是否显示 |
| isSystem | Boolean | 是否为初始预置（预置不可删除） |
| presetKey | String | 系统预设稳定标识；用户改名或改 emoji 后仍保持不变，自建分类为空 |
| bookId | ObjectId | 所属账本ID（所有分类均归属账本） |

### 3.4 成员（Member）
- **独立集合**：存储在 `members` 集合中，通过 openId 与 books 关联
- book.memberIds 仅存 openId 列表，成员详细信息从 members 集合批量查询

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | ObjectId | 成员ID |
| openId | String | 微信 OpenId |
| nickName | String | 昵称 |
| avatarUrl | String | 头像URL |
| role | String | "admin" / "member" |
| joinedAt | Date | 加入时间 |

### 3.5 月度预算（Budget）
- 每个账本每月最多一份预算，唯一键为 `bookId + month`
- 金额统一以分为单位；预算只统计支出，收入不占用预算
- 总预算必填，分类预算选填；分类预算仅关联支出大类
- 家庭成员均可查看，只有账本管理员可新增、修改、复制或删除预算

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | ObjectId | 预算ID |
| bookId | ObjectId | 所属账本ID |
| month | String | 月份，格式 `YYYY-MM` |
| totalAmount | Number | 月度总预算（分） |
| categoryLimits | Array | 分类预算数组，元素为 `{ categoryId, amount, name, icon }` |
| createdBy | String | 创建人 OpenId |
| createdAt | Date | 创建时间 |
| updatedAt | Date | 更新时间 |

## 5. 界面设计

### 5.1 首页（月度账目流）
**方案：分区卡片式**

- 顶部：月份选择器（可切换月份）
- 中间：月度汇总卡片（渐变色背景，显示结余/支出/收入）
- 预算卡片：
  - 未设置预算：显示“本月预算未设置”和“去设置”，不显示虚假的 0% 进度
  - 已设置预算：显示已用金额、预算金额、使用比例和剩余金额
  - 使用率达到 80% 显示预警样式，达到或超过 100% 显示超支样式
- 下方：近期账目列表（卡片形式，每条账目显示图标+分类+备注+金额+时间+记账人）
  - 大类记账显示“大类图标 + 大类名”
  - 小类记账显示“大类图标 + 小类名”，例如 `🍜 晚餐`、`🧧 春节红包`
  - 分类或父分类引用失效时显示“未分类”并输出诊断日志
- 右下角：悬浮 "+" 按钮，新增账目

### 5.2 统计页
**方案：按大类占比饼图**

- 月度支出分类饼图（ECharts 环形图），按**大类**（餐饮、交通、购物等）聚合
- 小类金额汇总到所属大类，避免碎片化
- 顶部可切换月份
- 饼图旁边显示分类明细列表（大类名+金额+占比），按金额降序排列
- 未设置预算时保留原有饼图和分类统计，仅在顶部显示“本月预算未设置”入口
- 已设置预算时显示总预算进度；设置了分类预算的大类在图例中显示分类预算进度

### 5.3 新增/编辑账目页（一页完成）
**必填字段：**
- 类型（支出/收入切换）
- 金额
- 分类（点击弹出层级分类弹窗，可选大类或小类）
- 日期（默认当天，可修改）
- 记账人（系统自动填充，当前用户）

**选填字段：**
- 备注
- 上传图片（最多 9 张，上传至微信云存储后存入 cloud file ID，路径前缀 test/ 或 prod/）

**分类管理入口：**
- 在分类选择弹窗中提供"管理"入口，跳转独立分类管理页
- 分类管理页支持：大类/小类的新增、改名、删除；大类图标从系统语义图库中选择
- 弹窗内支持快速添加大类（按名称推荐语义图标）和添加小类

**编辑态：**
- 记录详情页提供“编辑记录”入口，跳转 `/pages/add/add?mode=edit&recordId=...`，复用记一笔表单。
- 编辑态标题为“编辑记录”，提交按钮为“保存修改”，初始化原记录的类型、金额、分类、日期、备注和图片。
- 编辑时可修改支出/收入类型；一旦切换类型，已选分类清空，必须重新选择当前类型下的分类。
- 编辑保存调用 `record.update`，只更新业务字段和 `updatedBy/updatedByName/updatedAt`，保留 `createdBy/createdByName/createdAt`。
- 编辑态只上传本次新增的本地临时图片；已有 `cloud://` 图片保留 cloud file ID，删除图片仅移除记录引用，第一版不主动删除云存储文件。
- 新增记录仍按原逻辑触发预算提醒；编辑保存不弹预算预警，首页、统计和预算页面重新加载后按最新记录计算。

**记账结果反馈：**
- 账目必须先由云函数保存成功，再根据服务端返回的预算结果展示提醒
- 80% 首次跨线和分类预算超支使用页面内非阻塞提示条，不要求用户确认
- 分类预算达到或超过 100% 后，该分类每笔新增支出都提示；总预算仅首次跨过阈值时提示
- 提示条显示约 2 秒后自动返回首页，首页通过 `onShow` 刷新预算卡和最新账目

### 5.4 我的页
**结构：**
- 头像 + 昵称（可编辑）
- 预算管理入口（显示本月“未设置 / 进行中 / 预警 / 已超支”状态）
- 家庭入口（卡片形式，显示家庭名称）
- 关于（跳转到关于页）
- 退出登录

### 5.5 家庭详情页
**结构：**
- 家庭名称（管理员可编辑）
- 成员列表（头像+昵称+角色+移除按钮，移除功能开发中）
- 邀请成员按钮（通过微信分享卡片发送邀请码）
- 确认加入弹窗（被邀请人点击卡片后弹出）
- 提示弹窗（邀请过期/已使用/已在其他家庭等异常情况）

### 5.6 关于页
**内容：**
- 暖账 logo + 名称
- 版本号
- 用户协议链接
- 隐私政策链接

### 5.7 记录详情页
**功能：** 点击首页记录卡片进入，查看单条记录的完整信息

**布局：**
- 顶部：分类图标 + 名称、金额（支出橙色/收入绿色）、日期
- 备注区（如有备注）
- 图片网格：最多 9 张，点击调用 `wx.previewImage` 全屏浏览
- 记账信息：记账人、类型（支出/收入）
- 删除按钮：仅记录的创建者可见，点击确认后删除并返回首页

### 5.8 预算管理页
**功能：**
- 月份切换；历史月份只读，当前月和未来月份可设置
- 管理员可设置月度总预算，按需添加支出大类预算
- 支持复制上月预算到当前月份；目标月份已有预算时不覆盖
- 普通家庭成员只读查看预算及使用进度
- 删除预算需要二次确认，删除后首页和统计页恢复“未设置预算”状态

## 6. 交互流程

### 6.1 登录流程
1. 用户打开小程序 → 直接进入首页（Tab 栏可见，页面展示空状态）
2. 用户浏览首页、统计页、我的页，了解小程序功能
3. 用户进行需要登录的操作时（点击"+"记一笔、进入家庭页、编辑个人信息等），自动跳转登录页
4. 登录页展示用户协议 + 隐私政策 + "微信一键登录"按钮
5. 用户点击登录 → 微信授权 → 获取 openId、昵称、头像
6. 自动创建账本（或加入已有账本） → 返回触发登录的来源页面
7. 游客模式下不发起云函数请求，仅展示空状态 UI

### 6.2 邀请加入流程

**A 端（管理员）：**
1. 管理员进入"家庭详情"页
2. 点击"邀请成员"按钮 → 云函数生成6位邀请码（1小时有效，一次性使用）
3. 触发微信分享面板，邀请码嵌入分享卡片 `path` 参数
4. 管理员选择微信好友发送卡片

**B 端（被邀请人）：**
1. B 在微信聊天中点击分享卡片
2. 小程序打开 family 页，携带 `inviteCode` 参数
3. 判断登录状态：
   - 未登录 → 暂存邀请码到 Storage → 跳转登录页 → 登录成功后回跳 family 页
   - 已登录 → 继续
4. 云函数验证邀请码：
   - 有效 → 返回目标 `bookId` 并弹确认窗，显示目标账本名称
   - 同一用户存在未完成任务 → 返回 `joinStatus=processing`，允许继续原任务
   - 已过期/已被使用/不存在 → 弹提示窗，显示对应错误信息
5. B 选择：
   - "加入" → 前端自动重复调用分阶段迁移，直到返回 `status=completed`
   - 分阶段顺序：保存分类映射计划 → 重映射记录分类 → 迁移分类 → 迁移记录 → 校验 → 清理重复分类 → 加入成员并删除原账本
   - 任一步骤超时或网络中断时保留阶段和游标，下次调用从原任务继续
   - "暂不加入" → 弹窗关闭，邀请码仍有效（1小时内可重新点击卡片）
6. B 在1小时内想加入时，需重新点击微信聊天中的分享卡片

**全场景处理：**

| B 状态 | 码状态 | 处理 |
|--------|--------|------|
| 未登录 | 有效 | 暂存 → 登录 → 回跳 → 弹确认窗 |
| 未登录 | 过期/已用/无效 | 暂存 → 登录 → 回跳 → 提示对应错误 |
| 已登录独有账本 | 有效 | 弹确认窗 |
| 已登录独有账本 | 过期/已用/无效 | 提示对应错误 |
| 已是该家庭成员 | 已被使用 | 提示"你已是该家庭账本的成员" |
| 已是其他家庭成员 | 有效 | 提示"已有其他家庭，暂不支持切换" |
| 已是管理员 | 有效 | 提示"你已是该账本管理员" |

### 6.3 新增账目流程
1. 点击首页悬浮 "+" 按钮
2. 进入"记一笔"页面
3. 选择类型（支出/收入切换，切换后重新加载对应分类）
4. 点击分类区域 → 弹出层级分类弹窗（大类网格 + 小类列表 + "记在XX下"大类入口）
5. 选择大类后可选：
   - 点击"记在「XX」下"直接记账在大类
   - 选择下方小类记账在小类
6. 填写金额（键盘输入）
7. 选择日期（默认当天）
8. 选填：备注、图片（最多9张）
9. 点击"提交" → 保存到云数据库 → 返回首页刷新列表

**分类管理入口：**
- 在分类选择弹窗中提供"管理"入口，跳转独立分类管理页
- 分类管理页支持大类/小类的新增、改名（含 emoji）、删除（有记录时归并）

## 8. 关键决策汇总

| 问题 | 决策 |
|------|------|
| 账本模型 | 不区分个人/家庭；一人一个账本；婚后合并时历史账目迁移到家庭账本 |
| 成员可见性 | V1 所有成员可见所有账目 |
| 成员记账权 | 所有成员可记账；管理员可删除/修改他人账目（**实现中**） |
| 成员移除 | 管理员可移除成员（**移除功能开发中**） |
| 成员加入方式 | 微信分享卡片邀请制（邀请码嵌入分享路径，一次性有效，1小时过期） |
| 分类模型 | 层级分类 + type字段区分expense/income；每账本独立副本（isSystem标记预置）；大类/小类均可新增、改名、删除（预置不可删）；记账可选大类或小类 |
| 收入分类 | V1 实现完整的收入分类（工资/公积金/投资/副业兼职/闲置转卖/医疗报销/其他），与支出分类并列支持 |
| 首页布局 | 分区卡片式 |
| 新增入口 | 首页右下角悬浮按钮 |
| 账目录入 | 一页完成 |
| 分类选择 | 弹窗形式 + 层级交互 |
| 底部导航 | 3 Tab（首页/统计/我的）|
| 隐私协议 | 登录页展示《用户协议》和《隐私政策》 |
| 统计维度 | 按大类聚合的占比饼图（支出 only） |
| 用户资料持久化 | 服务端 members 集合存储头像昵称，登录时优先读取云端数据 |
| 分类合并 | 加入家庭时系统分类优先按 `presetKey` 匹配，旧数据回退到大类名称+类型/小类名称匹配；大类记账记录自动重映射 categoryId；无冲突小类迁移时重映射 parentId；自定义大类完整迁移 |
| 家庭合并可靠性 | 加入任务采用可重入分阶段状态机；重复分类在记录迁移与校验完成后才删除；源账本迁移期间禁止账目和分类写入 |
| 首页分类展示 | 大类记录显示大类图标+大类名；小类记录显示父大类图标+小类名 |
| 成员信息 | 存储在独立 members 集合，通过 openId 关联，family 页批量查询获取昵称头像 |
| 图片存储 | 上传至微信云存储，记录中存储 cloud file ID，支持跨设备查看 |
| 记录详情页 | 点击首页记录卡片进入，展示完整信息 + 图片网格，创建者可删除 |
| 游客模式 | 用户打开小程序直接进入首页体验界面，操作时按需引导登录（满足微信审核要求） |
| 分类初始化 | login 每次登录调用幂等 `init-database`；按 `categorySchemaVersion` 判断是否升级，按 `presetKey` 补齐缺失分类；仅全部写入成功后推进版本，失败时下次登录自动续补 |
| 会话恢复 | 冷启动调用只读 `login.restoreSession` 校正本地身份、账本和资料；主动退出通过 `manualLogout` 阻止静默恢复 |
| 邀请过期 | 生成后 1 小时；首次接受在服务端事务内复核，写入 `joinMigration.acceptedAt` 后同一用户可跨过期时间续跑 |
| 预算权限 | 家庭成员均可查看；仅账本 owner 可新增、修改、复制和删除 |
| 未设置预算展示 | 首页显示轻量引导卡，统计页保留原有图表并显示设置入口；不以 0 元预算计算进度 |
| 预算提醒 | 80% 仅首次跨线提醒；总预算 100% 仅首次跨线提醒；分类预算达到或超过 100% 后，每笔该分类支出都提醒。提醒为记账页非阻塞提示条，约 2 秒后自动返回首页 |
| 分类预算口径 | 只绑定支出大类；小类支出归集到所属大类，和统计页口径一致 |
| 家庭合并预算 | 保留目标家庭预算，迁移完成后清理来源个人账本预算，不覆盖目标预算 |
| 客户端更新 | 版本号由共享配置维护；新版本下载完成后不可取消地立即重启，下载失败时阻止继续使用并要求关闭后重新打开 |
| 首页加载性能 | 冷启动有本地 `openId/bookId` 时首页先使用本地会话加载记录，远程 `restoreSession` 继续后台校正；`onLoad/onShow` 首屏去重，分类和记录并行，记录先渲染，预算卡随后独立刷新 |
| 首页日期分组 | 首页记录按日期分组展示；仅“今天/昨天”使用相对文案，4、5 天前等普通日期显示 `6月21日 周日`，跨年显示年份；分组标题右侧显示当天收入/支出小计，记录卡片内不重复显示日期 |
